# MAVI Entregas — versões

Instaladores (APK) do aplicativo **MAVI Entregas**.

**Baixar a versão mais recente:** abra a página [Releases](../../releases/latest) e toque no arquivo `.apk`.

O app avisa sozinho quando sai uma versão nova. Para atualizar, toque em **Atualizar** no aviso e confirme a instalação.
Os dados do app (rota, base de endereços e histórico) continuam salvos.

O uso do aplicativo depende de chave de acesso.
